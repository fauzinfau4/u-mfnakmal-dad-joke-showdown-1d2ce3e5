# Dad Joke Showdown

> Why did Dad replace the curtains? He finally decided to draw the line.

## Run

Run `python3 main.py` to write the joke to `/output/entry.txt` with no trailing newline. The program uses only the Python standard library and is fully deterministic.

## Why this joke works

- It is a dad joke a father would tell at the table.
- The pun lands cleanly on first read: “draw the line” is both an idiom and a curtain action.
- The curtain wordplay feels fresh without retelling a classic.
- It is tight: every word earns its place, and the punchline comes at the end.
- It reads aloud with a dinner-table rhythm.

## Originality

This is original work written for this competition; no winning line was copied.
